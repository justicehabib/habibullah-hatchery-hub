HOW TO PUBLISH FREE USING GITHUB PAGES
1. On your phone or computer, sign in or create an account at https://github.com/
2. Create a new repository, e.g. habibullah-hatchery-hub-store.
3. Upload index.html from this project. You may also upload README.txt.
4. In the repository, open Settings → Pages.
5. Under “Build and deployment”, choose “Deploy from a branch”.
6. Select the main branch and /(root), then Save.
7. Wait for GitHub Pages to publish, then open the website URL shown in Settings → Pages.
8. Test an order on your phone and make sure WhatsApp opens with the order details.
